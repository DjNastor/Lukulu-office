# Lukulu Strategy HQ — Catalog-free public preview

Open index.html in a browser. The interactive Quick Strategy, Strategy Studio, Analytics and My Workflows screens work with browser-local storage.

This deliberately limited preview has no private catalog or connected service credentials. Actions create checklists only. For production, integrate it into the original Lukulu HQ front end with server-side Airtable, permissioned Drive access, verified Artist Growth profiles and approval-gated automations.

See SPEC.md for the implementation and security boundaries.
